FAQs

Common Questions

Is this considered an emergency call?

Most general repairs aren't emergencies, but if a fixture is actively leaking a large amount of water, treat it like one and call our emergency line.

Can you fix older galvanized pipe?

Yes, we regularly work on older galvanized and cast-iron plumbing found in Alpharetta's historic core.

Do you charge a flat rate?

Yes, you approve a flat price before any work starts, regardless of how long the repair actually takes to finish.

What if the repair turns out to be bigger than expected?

If we find something more involved once we're actually on-site, like a hidden leak behind a wall, we stop working and requote before continuing rather than running up the original flat price.

Does general repair work follow a specific code?

Yes. Repairs and any fixture replacements are done to the Georgia State Minimum Standard Plumbing Code, based on the current International Plumbing Code with state amendments.
